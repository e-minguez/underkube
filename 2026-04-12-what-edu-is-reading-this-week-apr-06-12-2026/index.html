What Edu is reading this week (April 06 - 12, 2026)

Posted on Apr 12, 2026

This week’s collection explores the latest in AI agent strategies, Linux security tools, and deep dives into LLM architectures.

Cloud, Kubernetes & Infrastructure

  • Prometheus Workshop - A comprehensive hands-on workshop for mastering Prometheus monitoring.
  • SpinKube - A project that streamlines developing, deploying, and operating WebAssembly (Wasm) workloads in Kubernetes.
  • Podman in Production: Quadlets, Secrets, Auto-Updates, and Docker Compatibility - An opinionated guide to using Podman on Linux servers as a modern alternative to Docker.

AI, Agents & Tools

  • The advisor strategy: Give Sonnet an intelligence boost with Opus - A clever pattern pairing Opus as an advisor with smaller models to achieve high intelligence at lower costs.
  • 12k AI-generated blog posts added in a single commit - A Hacker News discussion on the implications of mass-produced AI content.
  • Next-Generation Agent Security | nono - An OS-enforced capability sandbox designed for running untrusted AI agents securely.
  • LLM Visualization / Spreadsheets are all you need.ai: Educational resources for understanding LLM internals through 3D visualization and spreadsheet implementations.
  • rasbt/LLMs-from-scratch - A step-by-step guide to implementing a ChatGPT-like LLM in PyTorch.
  • Working with LLMs using Open WebUI - A tutorial on setting up local GenAI development environments using Rancher Desktop.
  • milla-jovovich/mempalace - An open-source AI memory system that achieves high benchmark scores.
  • alexmt/claude-ls - A terminal UI for managing Claude Code sessions efficiently.
  • JuliusBrussee/caveman / dlepold/caveman-distillate: AI output compression tools that reduce token usage by adopting a “caveman” speaking style.
  • arman-bd/guppylm - A tiny 9M parameter LLM designed to talk like a small fish.
  • Mvidia - A project exploring AI hardware or software optimizations.

Linux & Systems

  • Little Snitch for Linux / evilsocket/opensnitch: Modern application firewalls for Linux inspired by the classic macOS utility.
  • 0xAX/linux-insides - A deep-dive book-in-progress about the Linux kernel internals.
  • Porting Mac OS X to the Nintendo Wii - A fascinating project running Mac OS X 10.0 natively on Nintendo Wii hardware.

Development, Web & Tools

  • pocket-id/pocket-id - A simple OIDC provider that allows users to authenticate with passkeys.
  • SearXNG instances / Documentation: A privacy-respecting metasearch engine and its official documentation.
