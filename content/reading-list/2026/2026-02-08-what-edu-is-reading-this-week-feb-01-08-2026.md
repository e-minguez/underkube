This week is a massive roundup. The AI agent ecosystem is exploding with new tools (and security leaks), while the "privacy & tunneling" toolbox gets a major refill.

![what-edu-is-reading-this-week-feb-02-08-2026](/images/2026-02-08-what-edu-is-reading-this-week-feb-01-08.png)

## AI, Agents & Security

* [**Moltbook Database Exposure**](https://www.wiz.io/blog/exposed-moltbook-database-reveals-millions-of-api-keys) - Wiz reveals a massive breach in "Moltbook" where millions of API keys were exposed.
* [**Moltroad**](https://x.com/i/status/2017660254234845664) - A "Silk Road" for AI agents to list and trade black market items.
* [**P*rnhub for Agents**](https://x.com/i/status/2017793023287931169) - Exactly what it sounds like... but for AI agents.
* [**Nanobot**](https://github.com/HKUDS/nanobot) - A lightweight alternative to OpenClaw that delivers core AI assistant capabilities.
* [**Nanoclaw**](https://github.com/gavrielc/nanoclaw) - A slimmed-down version of ClawdBot achieved in just 500 lines of code.
* [**FreeClaw**](https://github.com/KLD997/FreeClaw) - Another open-source entry in the "Claw" agent ecosystem.
* [**Fluid.sh**](https://github.com/aspectrr/fluid.sh?tab=readme-ov-file#-demo) - A tool to create ephemeral KVM sandboxes for safe AI agent execution.
* [**Sandbox Agent**](https://sandboxagent.dev/) / [**Repo**](https://github.com/rivet-dev/sandbox-agent/blob/main/gigacode%2FREADME.md) - A universal API to control coding agents inside sandboxes over HTTP (an enhancement for OpenCode, not a fork).
* [**Bandsox**](https://github.com/HACKE-RC/Bandsox) - A library for managing Firecracker microVMs, designed for sandboxing AI agents.
* [**Grounded Take on Agentic Coding**](https://iximiuz.com/en/posts/grounded-take-on-agentic-coding/) - Ivan Velichko's realistic look at using AI agents in production environments.
* [**Claudernetes**](https://github.com/xchangeee/claudernetes/) - An ArgoCD plugin that uses Claude Code to dynamically generate Kubernetes manifests.
* [**MCP Gateway**](https://github.com/Kuadrant/mcp-gateway) - A gateway for the Model Context Protocol (MCP) by Kuadrant.
* [**AI in the Terminal**](https://github.com/theNetworkChuck/ai-in-the-terminal/tree/main) - NetworkChuck's collection of scripts/tools for using AI directly in the CLI.
* [**Claude Code Local Models**](https://boxc.net/blog/2026/claude-code-connecting-to-local-models-when-your-quota-runs-out/) - How to connect Claude Code to local models when you run out of quota.
* [**Bloom Security on "Claw"**](https://medium.com/bloom-security/another-issue-i-may-need-a-claw-nex-dee799e7740c) - Security analysis related to the rising "Claw" bot ecosystem.
* [**Automation to Infection Part II**](https://blog.virustotal.com/2026/02/from-automation-to-infection-part-ii.html) - VirusTotal analyzes how attackers are leveraging automation and AI.
* [**AI Generated Code Quality**](https://agilepainrelief.com/blog/ai-generated-code-quality-problems/) - A discussion on the potential long-term quality problems of AI-generated code.
* [**My AI Adoption Journey**](https://mitchellh.com/writing/my-ai-adoption-journey) - Mitchell Hashimoto reflects on his personal journey adopting AI tools.
* [**The Adolescence of Technology**](https://www.darioamodei.com/essay/the-adolescence-of-technology) - An essay by Dario Amodei on the current developmental stage of AI.

## Privacy, Tunnels & Proxies

* [**Outline**](https://getoutline.org/intl/es/) - An easy way to set up your own VPN server.
* [**ByeDPI**](https://github.com/hufrea/byedpi) - A local SOCKS/HTTP proxy designed to bypass Deep Packet Inspection.
* [**Chisel**](https://github.com/jpillora/chisel) - A fast TCP/UDP tunnel over HTTP.
* [**WStunnel**](https://github.com/erebe/wstunnel) - Tunnel traffic over WebSocket to bypass restrictive firewalls.
* [**Xray-core**](https://github.com/XTLS/Xray-core) - The core of Project X, a platform for building proxies to bypass network restrictions.
* [**Shadowsocks**](https://shadowsocks.org/) - A secure socks5 proxy designed to protect your internet traffic.
* [**SoftEther VPN**](https://www.softether.org/) - A powerful multi-protocol VPN software.

## Cloud, Infrastructure & Tools

* [**Code on Incus**](https://github.com/mensfeld/code-on-incus) - Run coding agents in isolated Incus containers with session persistence.
* [**Snapscheduler**](https://github.com/backube/snapscheduler) - Snapshot scheduler for Kubernetes CSI volumes.
* [**k4s**](https://k4s.pwnx.eu/) / [**Commit**](https://github.com/LywwKkA-aD/k4s/commit/e49e20af2fe43db0e7b4cd7297f5522e2f3c9ef9) - An alternative to k9s (link includes the removal of Claude MD files).
* [**WebZFS**](https://github.com/webzfs/webzfs) - A modern, web-based management interface for ZFS.
* [**Whosthere**](https://github.com/ramonvermeulen/whosthere) - A TUI-based LAN discovery tool (mDNS, SSDP, ARP).
* [**Fresh**](https://getfresh.dev/) - A terminal text editor you can just use.
* [**Minimal**](https://github.com/rtvkiz/minimal) - A Minimal CVE Hardened container image collection.
* [**Nextcloud Ada Engine**](https://nextcloud.com/blog/a-new-data-access-architecture-for-nextcloud-introducing-the-ada-engine/) - Nextcloud's new high-performance data access architecture.
* [**Git Based Packaging**](https://bazgab.github.io/posts/git-based-packaging-workflow/) - A workflow for managing software packaging using Git.
