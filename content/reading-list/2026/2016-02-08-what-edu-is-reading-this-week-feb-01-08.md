This week the AI agent ecosystem gets a reality check with the Moltbook database exposure, while new tools like Fluid.sh and Sandbox Agent aim to make agentic infrastructure safer and more standardized.

## AI, Agents & Security

* [**Moltbook Database Exposure**](https://www.wiz.io/blog/exposed-moltbook-database-reveals-millions-of-api-keys) - Wiz reveals a security breach in "Moltbook" (a social network for agents) where an exposed database revealed millions of API keys.
* [**Code on Incus**](https://github.com/mensfeld/code-on-incus) - Run coding agents in isolated Incus containers (sandboxes) with session persistence, workspace isolation, and multi-slot support.
* [**Nanobot**](https://github.com/HKUDS/nanobot) - A lightweight (4,000 LOC) alternative to OpenClaw that delivers core AI assistant capabilities without the bloat.
* [**Fluid.sh**](https://github.com/aspectrr/fluid.sh?tab=readme-ov-file#-demo) - A tool to create ephemeral KVM sandboxes where AI agents can execute infrastructure tasks safely before applying them to production.
* [**Sandbox Agent**](https://github.com/rivet-dev/sandbox-agent/blob/main/gigacode%2FREADME.md) - A universal API to control coding agents (Claude Code, OpenCode, etc.) inside sandboxes over HTTP.
* [**Claudernetes**](https://github.com/xchangeee/claudernetes/) - An ArgoCD plugin that uses Claude Code to dynamically generate Kubernetes manifests, reducing the need to write raw YAML.
* [**AI Generated Code Quality**](https://agilepainrelief.com/blog/ai-generated-code-quality-problems/) - A discussion on the potential long-term quality problems introduced by AI-generated code.
* [**Automation to Infection Part II**](https://blog.virustotal.com/2026/02/from-automation-to-infection-part-ii.html) - VirusTotal analyzes how attackers are leveraging automation and AI in modern infection chains.
* [**My AI Adoption Journey**](https://mitchellh.com/writing/my-ai-adoption-journey) - Mitchell Hashimoto reflects on his personal journey adopting AI tools.
* [**The Adolescence of Technology**](https://www.darioamodei.com/essay/the-adolescence-of-technology) - An essay by Dario Amodei on the current developmental stage of AI technology.

## Cloud, Network & Tools

* [**Fresh**](https://getfresh.dev/) - A terminal text editor you can just use.
* [**Whosthere**](https://github.com/ramonvermeulen/whosthere) - A TUI-based LAN discovery tool that scans for devices using mDNS, SSDP, and ARP.
* [**WebZFS**](https://github.com/webzfs/webzfs) - A modern, web-based management interface for ZFS pools, datasets, and snapshots.
* [**Nextcloud Ada Engine**](https://nextcloud.com/blog/a-new-data-access-architecture-for-nextcloud-introducing-the-ada-engine/) - Nextcloud introduces the Ada Engine, a new high-performance data access architecture.
* [**Git Based Packaging**](https://bazgab.github.io/posts/git-based-packaging-workflow/) - A workflow for managing software packaging using Git.

## Privacy & Tunneling

* [**Outline**](https://getoutline.org/intl/es/) - Outline makes it easy to create a VPN server, giving anyone access to the free and open internet.
* [**ByeDPI**](https://github.com/hufrea/byedpi) - A local SOCKS/HTTP proxy designed to bypass Deep Packet Inspection (DPI).
* [**Chisel**](https://github.com/jpillora/chisel) - A fast TCP/UDP tunnel over HTTP, useful for passing through restrictive firewalls.
* [**WStunnel**](https://github.com/erebe/wstunnel) - A tool to tunnel traffic over WebSocket, allowing you to bypass firewalls that block standard VPN protocols.
* [**Xray-core**](https://github.com/XTLS/Xray-core) - A platform for building proxies to bypass network restrictions (Project X).
* [**Shadowsocks**](https://shadowsocks.org/) - A secure socks5 proxy, designed to protect your internet traffic.
* [**SoftEther VPN**](https://www.softether.org/) - One of the world's most powerful and easy-to-use multi-protocol VPN software.

## Gaming & General

* [**Playdate Games**](https://pdgamez.com/) - A repository or collection of games for the Playdate handheld console.
* [**R36S Multiboot**](https://github.com/R36S-Stuff/R36S-Multiboot) / [**Armbian**](https://github.com/R36S-Stuff/R36S-Armbian): Resources for running multiple OSes and Armbian on the R36S retro handheld.
* [**Mr. Doob**](https://mrdoob.com/) - The personal site of the creator of Three.js, featuring various WebGL experiments.
* [**Base64 Padding**](https://lars.ingebrigtsen.no/2026/02/02/whats-up-with-all-those-equals-signs-anyway/) - A blog post explaining the purpose of the equals signs (`=`) at the end of Base64 strings.
