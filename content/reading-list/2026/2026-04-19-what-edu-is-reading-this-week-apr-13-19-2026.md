This week's highlights feature the latest in AI agent orchestration, local LLM accessibility on Apple hardware, and a nostalgic trip through classic Mac OS emulation and ports.

![Reading list header image](/images/2026-04-19-what-edu-is-reading-this-week-apr-13-19.png)

## Cloud, Kubernetes & Infrastructure
* [**Flightdeck**](https://github.com/tsuz/flightdeck) - A fault-tolerant, event-driven AI agent framework built on Kafka that manages session context and infrastructure.
* [**Running AI agents safely in a microVM using Docker Sandbox**](https://andrewlock.net/running-ai-agents-safely-in-a-microvm-using-docker-sandbox/) - A technical guide on isolating AI coding agents in microVMs to enable unrestricted tool permissions without compromising host security.

## AI, Agents & Tools
* [**AI Agent Orchestration**](https://blog.apify.com/ai-agent-orchestration/) - A technical guide on building multi-agent systems using the OpenAI Agents SDK and Apify's web scraping tools.
* [**How to Build an AI Agent**](https://arize.com/blog/how-to-build-an-ai-agent/) - A comprehensive overview of building AI agents using frameworks like smolagents and LangGraph, focusing on iterative reasoning and tool integration.
* [**My AI-Assisted Workflow**](https://www.maiobarbero.dev/articles/ai-assisted-workflow/) - A Tech Lead's structured development process that prioritizes rigorous planning and PRD creation before using AI for code implementation.
* [**Automate work with routines (Claude Code)**](https://code.claude.com/docs/en/routines) - Documentation for creating and managing automated Claude Code tasks triggered by schedules, API calls, or GitHub events.
* [**Common Crawl**](https://commoncrawl.org/) - A non-profit repository providing free, open access to over 300 billion web pages for large-scale data analysis and research.
* [**Gemini Caveman Extension**](https://github.com/chrisfair/gemini-caveman) - A CLI extension that implements an ultra-compressed communication mode for Gemini to reduce token usage while maintaining accuracy.
* [**Darkbloom**](https://darkbloom.dev/) - A decentralized inference network that leverages idle Apple Silicon hardware to provide low-cost, encrypted AI compute.
* [**Apfel**](https://github.com/Arthur-Ficial/apfel) - A tool providing local, OpenAI-compatible access to built-in language models on Apple Silicon Macs without cloud APIs.
* [**Transformer Lab**](https://lab.cloud/) - An open-source machine learning research platform for distributed training, experiment tracking, and model evaluation.

## Linux & Systems
* [**Too much discussion of the XOR swap trick**](https://heather.cafe/posts/too_much_xor_swap_trick/) - A deep dive into the XOR swap trick's bitwise logic and its practical utility in the era of modern compilers.
* [**KeePassChi**](https://codeberg.org/keepasschi) - A community-driven fork of KeePassXC that explicitly rejects the integration of LLM-based features.
* [**openSUSE Git Packaging Workflow**](https://en.opensuse.org/openSUSE:Git_Packaging_Workflow) - Documentation of openSUSE's shift toward a Git-centric model using Gitea for package source management.
* [**Awesome Package Maintainer**](https://github.com/jubalh/awesome-package-maintainer) - A curated list of tools, tips, and best practices for software packaging across various Linux distributions.
* [**Smol Machines**](https://smolmachines.com/) - A CLI tool for running custom Linux virtual machines locally with hardware-level isolation and sub-second cold starts.
* [**Tell HN: Docker pull fails in Spain due to football Cloudflare block**](https://news.ycombinator.com/item?id=47738883) - A discussion on Spanish ISPs blocking Cloudflare IPs during football matches, disrupting developer workflows and smart devices.

## Development, Web & Tools
* [**WACLI**](https://github.com/steipete/wacli) - A command-line interface for WhatsApp that enables local message history syncing and fast offline search.
* [**Setting up SheepShaver for OSX/macOS**](https://www.emaculation.com/doku.php/sheepshaver_mac_os_x_setup) - A comprehensive guide for configuring the SheepShaver emulator to run classic Mac OS versions on modern hardware.
* [**Mac OS 9 for macOS**](https://www.mendelson.org/macos9osx.html) - A self-contained SheepShaver package that simplifies running Mac OS 9.0.4 on modern macOS with integrated file sharing.
* [**Why do NES games look different in emulators?**](https://www.youtube.com/watch?v=7JupB4QHyGI) - A video explanation of the technical reasons behind color and graphic discrepancies between emulators and original CRT hardware.

## Gaming, Fun & Misc

* [**The Future of Everything is Lies, I Guess: New Jobs**](https://aphyr.com/posts/419-the-future-of-everything-is-lies-i-guess-new-jobs) - An analysis of the new professional roles emerging from the deployment of machine learning.
