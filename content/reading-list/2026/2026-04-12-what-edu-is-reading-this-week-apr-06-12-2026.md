This week's collection explores the latest in AI agent strategies, Linux security tools, and deep dives into LLM architectures.

## Cloud, Kubernetes & Infrastructure
* [**Prometheus Workshop**](https://o11y-workshops.gitlab.io/workshop-prometheus/) - A comprehensive hands-on workshop for mastering Prometheus monitoring.
* [**SpinKube**](https://www.spinkube.dev/) - A project that streamlines developing, deploying, and operating WebAssembly (Wasm) workloads in Kubernetes.
* [**Podman in Production: Quadlets, Secrets, Auto-Updates, and Docker Compatibility**](https://blog.hofstede.it/podman-in-production-quadlets-secrets-auto-updates-and-docker-compatibility/) - An opinionated guide to using Podman on Linux servers as a modern alternative to Docker.

## AI, Agents & Tools
* [**The advisor strategy: Give Sonnet an intelligence boost with Opus**](https://claude.com/blog/the-advisor-strategy) - A clever pattern pairing Opus as an advisor with smaller models to achieve high intelligence at lower costs.
* [**12k AI-generated blog posts added in a single commit**](https://news.ycombinator.com/item?id=47640722) - A Hacker News discussion on the implications of mass-produced AI content.
* [**Next-Generation Agent Security | nono**](https://nono.sh/) - An OS-enforced capability sandbox designed for running untrusted AI agents securely.
* [**LLM Visualization**](https://bbycroft.net/llm) / [**Spreadsheets are all you need.ai**](https://spreadsheets-are-all-you-need.ai/): Educational resources for understanding LLM internals through 3D visualization and spreadsheet implementations.
* [**rasbt/LLMs-from-scratch**](https://github.com/rasbt/LLMs-from-scratch) - A step-by-step guide to implementing a ChatGPT-like LLM in PyTorch.
* [**Working with LLMs using Open WebUI**](https://docs.rancherdesktop.io/tutorials/working-with-llms) - A tutorial on setting up local GenAI development environments using Rancher Desktop.
* [**milla-jovovich/mempalace**](https://github.com/milla-jovovich/mempalace) - An open-source AI memory system that achieves high benchmark scores.
* [**alexmt/claude-ls**](https://github.com/alexmt/claude-ls) - A terminal UI for managing Claude Code sessions efficiently.
* [**JuliusBrussee/caveman**](https://github.com/JuliusBrussee/caveman) / [**dlepold/caveman-distillate**](https://github.com/dlepold/caveman-distillate): AI output compression tools that reduce token usage by adopting a "caveman" speaking style.
* [**arman-bd/guppylm**](https://github.com/arman-bd/guppylm) - A tiny 9M parameter LLM designed to talk like a small fish.
* [**Mvidia**](https://jaso1024.com/mvidia/) - A project exploring AI hardware or software optimizations.

## Linux & Systems
* [**Little Snitch for Linux**](https://obdev.at/products/littlesnitch-linux/index.html) / [**evilsocket/opensnitch**](https://github.com/evilsocket/opensnitch): Modern application firewalls for Linux inspired by the classic macOS utility.
* [**0xAX/linux-insides**](https://github.com/0xAX/linux-insides) - A deep-dive book-in-progress about the Linux kernel internals.
* [**Porting Mac OS X to the Nintendo Wii**](https://bryankeller.github.io/2026/04/08/porting-mac-os-x-nintendo-wii.html) - A fascinating project running Mac OS X 10.0 natively on Nintendo Wii hardware.

## Development, Web & Tools
* [**pocket-id/pocket-id**](https://github.com/pocket-id/pocket-id) - A simple OIDC provider that allows users to authenticate with passkeys.
* [**SearXNG instances**](https://searx.space/#) / [**Documentation**](https://docs.searxng.org/index.html): A privacy-respecting metasearch engine and its official documentation.
