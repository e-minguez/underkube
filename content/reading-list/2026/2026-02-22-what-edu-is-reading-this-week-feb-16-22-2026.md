This week's reading list is heavily focused on Kubernetes observability, AI orchestration, and some very handy tools for navigating the modern web.

![2026-02-22-what-edu-is-reading-this-week-feb-16-22-2026](/images/2026-02-22-what-edu-is-reading-this-week-feb-16-22.png)

## Cloud, Kubernetes & Infrastructure

* **Fatih Koc's Observability & Infrastructure Series:**
  * [**Kubernetes Security Observability**](https://fatihkoc.net/posts/kubernetes-security-observability/) - A guide to establishing effective security observability in your Kubernetes clusters.
  * [**OpenTelemetry Kubernetes Pipeline**](https://fatihkoc.net/posts/opentelemetry-kubernetes-pipeline/) - A walkthrough on setting up a robust OpenTelemetry pipeline specifically for Kubernetes.
  * [**Monitoring with kube-prometheus-stack**](https://fatihkoc.net/posts/monitoring-kube-prometheus-stack/?ref=hackernoon.com) - A practical tutorial on monitoring using the popular `kube-prometheus-stack`.
  * [**Production-Ready Terraform**](https://fatihkoc.net/posts/production-ready-terraform/) - Best practices and architectural patterns for writing production-ready Terraform code.
  * [**Stop Hunting Logs: OpenTelemetry**](https://hackernoon.com/stop-hunting-logs-how-opentelemetry-brings-metrics-logs-and-traces-together) - How OpenTelemetry successfully brings metrics, logs, and traces together into a single pane of glass. 

* [**crust-gather**](https://github.com/crust-gather/crust-gather) - A kubectl debugging plugin to collect full or partial cluster state and serve it via an API server, acting like a Kubernetes "time machine".
* [**Cluster API Provider for Incus**](https://github.com/lxc/cluster-api-provider-incus) - The official Kubernetes Cluster API (CAPI) provider for LXC/Incus, allowing you to manage Incus clusters declaratively.
* [**K3s Distributed Multicloud Networking**](https://docs.k3s.io/networking/distributed-multicloud) - Official K3s documentation on setting up distributed multicloud networking.
* [**Find AWS AMI Owner ID**](https://michaelheap.com/aws-find-ami-owner-id/) - A quick and handy guide to locating the owner ID of an AWS AMI.

## AI, Agents & Tools

* [**Peter Steinberger on OpenClaw**](https://steipete.me/posts/2026/openclaw) - Peter Steinberger talks about recently joining OpenAI after creating OpenClaw.
* [**Grove**](https://github.com/ai-dynamo/grove/tree/main) - A Kubernetes API that provides a single declarative interface for orchestrating any AI inference workload — from simple, single-pod deployments to complex multi-node, disaggregated systems. 
* [**llmfit**](https://github.com/AlexsJones/llmfit) - A terminal tool that right-sizes LLM models to your system's RAM, CPU, and GPU.
* [**Prompts.chat**](https://github.com/f/prompts.chat) - An incredibly comprehensive and curated repository of awesome ChatGPT prompts.
* [**OpenCode Cafe**](https://www.opencode.cafe/) - A community hub or platform revolving around OpenCode and open-source AI assistance.

## Linux & Systems

* [**SUSE NVIDIA vGPU Documentation**](https://documentation.suse.com/sles/15-SP6/html/SLES-all/article-nvidia-vgpu.html) - Official SUSE Linux Enterprise Server 15 SP6 documentation for configuring and managing NVIDIA vGPU deployments.

## General, Web & Misc

* [**Tebasaltar**](https://github.com/ogarcia/tebasaltar/tree/master) - A tool to bypass Tebas' internet blocks happening in Spain when a football match is on TV.
* [**PressReleased**](https://pressreleased.alwaysdata.net/) - A website to help bypass paywalls.
* [**Readme Club**](https://www.readme.club/start) - A website with tips and utilities for the Xteink X4.
