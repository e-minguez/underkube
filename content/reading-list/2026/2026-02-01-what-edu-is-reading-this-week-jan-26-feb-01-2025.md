## Cloud & Kubernetes

* [**Kubernetes at $2/month**](https://kube.fm/kubernetes-cluster-2-dollars-varnit) - A guide on running a functional Kubernetes cluster for just $2 a month.
* [**EmeritOSS Backs MinIO**](https://thenewstack.io/chainguard-emeritoss-backs-minio-other-orphaned-projects/) - Chainguard's EmeritOSS initiative steps in to support MinIO and other "orphaned" open-source projects.
* [**Kubernetes GPU Guide**](https://docs.nvidia.com/datacenter/cloud-native/kubernetes/latest/index.html) - NVIDIA's official documentation for GPU-accelerated Kubernetes.
* [**Etcd Tuning**](https://etcd.io/docs/v3.6/tuning/) - Official guide on tuning etcd for performance and stability.
* [**Google IP Ranges**](https://www.gstatic.com/ipranges/goog.json) - The JSON feed of Google's public IP ranges.
* [**Nodes Proxy RCE**](https://grahamhelton.com/blog/nodes-proxy-rce) - A deep dive into a Kubernetes authorization bypass where `nodes/proxy` GET permissions allow command execution.
* [**Running Self-Hosted LLMs on Kubernetes**](https://www.reddit.com/r/kubernetes/comments/1qr50kl/running_selfhosted_llms_on_kubernetes_a_complete/) - A guide on how to run self-hosted LLMs on Kubernetes.

## AI, Agents & Tools

* [**OpenClaw**](https://openclaw.ai/blog/introducing-openclaw) - Introducing OpenClaw, a new open-source AI agent framework.
* [**ClawdBot**](https://www.linkedin.com/pulse/clawdbot-docker-model-runner-private-personal-ai-assistant-docker-s6xbc) - ClawdBot/MoltBot/OpenClaw running as a Docker Model Runner.
* [**Docker Model Runner**](https://docs.docker.com/ai/model-runner/) - Documentation for Docker's new Model Runner, simplifying local AI model execution.
* [**Docker Cagent**](https://docs.docker.com/ai/cagent/) - Documentation for Docker's "Cagent" (Container Agent) capabilities.
* [**MultiClaude**](https://github.com/dlorenc/multiclaude) / [**Intro Blog**](https://dlorenc.medium.com/a-gentle-introduction-to-multiclaude-36491514ba89): A tool for running multiple Claude instances in parallel for enhanced reasoning and verification.
* [**Qwen3-TTS**](https://github.com/QwenLM/Qwen3-TTS) - The latest Text-to-Speech model from the Qwen team.
* [**RunPod Pricing**](https://www.runpod.io/pricing) - Current pricing for GPU cloud computing on RunPod.
* [**Moltbook security hole**](https://x.com/javilop/status/2017878873124265985) - Moltbook (OpenClaw's own reddit) security hole exposes critical information (Spanish)

## Linux, System & Hacks

* [**SmolBSD**](https://www.reddit.com/r/BSD/comments/1qlj0n7/smolbsd_create_a_netbsd_microvm_using_a_dockerfile/) - A project to create a NetBSD MicroVM using a Dockerfile.
* [**Time Machine in FreeBSD Jail**](https://it-notes.dragas.net/2026/01/28/time-machine-freebsd-jail/) - A guide on setting up an Apple Time Machine backup server inside a FreeBSD Jail.
* [**Void Linux ZFS Hibernation**](https://it-notes.dragas.net/2025/12/22/void-linux-zfs-hibernation-guide/) - A guide to configuring hibernation on Void Linux with ZFS.
* [**libeconf**](https://github.com/openSUSE/libeconf) - A library for parsing and managing configuration files in a unified way.
* [**Ungoogled Software**](https://ungoogled-software.github.io/) - A repository of software that has been stripped of Google integration and tracking.
* [**Luci Theme Aurora**](https://github.com/eamonxg/luci-theme-aurora) - A modern, clean theme for the OpenWRT LuCI web interface.
