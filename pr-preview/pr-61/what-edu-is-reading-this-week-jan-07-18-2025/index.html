What Edu is reading this week (Jan 5 - 18, 2026)

Posted on Jan 18, 2026

I missed last week’s post because I was too busy trying to beat my high score in UEFI Zaxxon. To make it up to you, here is a double-sized roundup covering the last two weeks.

Cloud & Kubernetes

  • Kubernetes Dashboard Archiving - A discussion in the Kubernetes SIG-UI group regarding the potential archiving of the Kubernetes Dashboard project.
  • Ingress Controllers Spreadsheet - A comprehensive, community-maintained spreadsheet comparing various Kubernetes Ingress Controllers.
  • MinIO Alternatives - A look at alternatives to MinIO for single-node local S3 compatible storage, such as SeaweedFS and Garage.
  • Copacetic - A CLI tool for directly patching container images using reports from vulnerability scanners.
  • KubeVirt Stretched L2 - A guide on setting up a stretched Layer 2 network between clusters using KubeVirt.
  • ORAS Quickstart - Quickstart guide for ORAS (OCI Registry As Storage), allowing you to store arbitrary artifacts in OCI registries.

DevOps, AI & Tools

  • SkyVM Announcement - Dioxus Labs announces SkyVM, a platform for instant-boot cloud virtual machines designed for AI agent coding tasks.
  • Gas Town / GitHub Repo: Steve Yegge’s latest project, “Gas Town”, a new take on the IDE for 2026 designed to orchestrate multiple AI agents.
  • The Key to Agentic Success - An article arguing that the Unix philosophy and Bash are the keys to success for AI agents.
  • Bash Course - A repository containing a course on Bash scripting.
  • Mosh Static Multiarch - Static binaries for Mosh (Mobile Shell) supporting multiple architectures.
  • OpenCode - A platform for open AI coding.

Linux, System & Hardware

  • Win8DE - A project that recreates the Windows 8 Desktop Environment experience on Linux using Wayland.
  • UEFI Zaxxon / Firmware Security Tag / GitHub Repo: A developer has recreated the classic arcade game Zaxxon to run directly as UEFI firmware, written in x86 assembly.
  • UAPI Configuration Files - The Userspace API (UAPI) Group’s specification for configuration files in Linux systems.
  • Kernel Bugs - A blog post from Pebblebed discussing Linux kernel bugs.
  • ESPTimeCast - A WiFi-connected LED matrix clock and weather station based on ESP8266/ESP32.

Web & Design

  • What happened to WebAssembly? - A blog post exploring the current state and adoption of WebAssembly.
  • Amiga Pointer Archive - A museum-like collection of mouse pointers from the Amiga era.
  • C.A.F.E - The “Third Way” for Home Assistant automations. Node-RED-style visual editing that compiles to 100% native YAML. No external engine required.

General & Misc

  • Illness in Space - (Spanish) An article by Daniel Marín about emergency returns of spacecraft due to astronaut health issues.
  • The Napoleon Technique - An article on the productivity method attributed to Napoleon Bonaparte.
  • Stimulation Clicker - A clicker game by Neal.fun designed to overload your stimulation.
