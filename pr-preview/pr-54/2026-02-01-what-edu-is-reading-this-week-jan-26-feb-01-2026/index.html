What Edu is reading this week (Jan 26 - Feb 1, 2026)

Posted on Feb 1, 2026

While I try to cover everything from budget Kubernetes to BSD tricks, the star of the show this week is of course ClawdBot/MoltBot/OpenClaw.

Photo courtesy of Alejandro Martinez :)

Cloud & Kubernetes

  • Kubernetes at $2/month - A guide on running a functional Kubernetes cluster for just $2 a month.
  • EmeritOSS Backs MinIO - Chainguard’s EmeritOSS initiative steps in to support MinIO and other “orphaned” open-source projects.
  • Kubernetes GPU Guide - NVIDIA’s official documentation for GPU-accelerated Kubernetes.
  • Etcd Tuning - Official guide on tuning etcd for performance and stability.
  • Google IP Ranges - The JSON feed of Google’s public IP ranges.
  • Nodes Proxy RCE - A deep dive into a Kubernetes authorization bypass where nodes/proxy GET permissions allow command execution.
  • Running Self-Hosted LLMs on Kubernetes - A guide on how to run self-hosted LLMs on Kubernetes.

AI, Agents & Tools

  • OpenClaw - Introducing OpenClaw, a new open-source AI agent framework.
  • ClawdBot - ClawdBot/MoltBot/OpenClaw running as a Docker Model Runner.
  • Docker Model Runner - Documentation for Docker’s new Model Runner, simplifying local AI model execution.
  • Docker Cagent - Documentation for Docker’s “Cagent” (Container Agent) capabilities.
  • MultiClaude / Intro Blog: A tool for running multiple Claude instances in parallel for enhanced reasoning and verification.
  • Qwen3-TTS - The latest Text-to-Speech model from the Qwen team.
  • RunPod Pricing - Current pricing for GPU cloud computing on RunPod.
  • Moltbook security hole - Moltbook (OpenClaw’s own reddit) security hole exposes critical information (Spanish)

Linux, System & Hacks

  • SmolBSD - A project to create a NetBSD MicroVM using a Dockerfile.
  • Time Machine in FreeBSD Jail - A guide on setting up an Apple Time Machine backup server inside a FreeBSD Jail.
  • Void Linux ZFS Hibernation - A guide to configuring hibernation on Void Linux with ZFS.
  • libeconf - A library for parsing and managing configuration files in a unified way.
  • Ungoogled Software - A repository of software that has been stripped of Google integration and tracking.
  • Luci Theme Aurora - A modern, clean theme for the OpenWRT LuCI web interface.

Gaming & Fun

  • Playdate Go - A Go framework for developing games for the Playdate console.
  • Doom Buds - Running Doom on headphones? of course!.
  • PSX LibCrypt Protection - (Spanish) An article detailing the history and cracking of the PlayStation’s LibCrypt copy protection.
  • RotClock - A fun project to have a unique physical rotating clock.

General & Misc

  • Omarchy - A curated list for “Omarchy”, an opinionated Linux distribution based on Arch and Hyprland by DHH.
  • Compute Gardener - Steward Carbon-Aware Computing Across Any Infrastructure.
  • X / Twitter Status - Hacking clawdbot and eating lobster souls.
  • Mastodon Post / Matrix.org Response - A thread about Cloudflare’s “vibe coded” blog post claiming they implemented Matrix on Cloudflare Workers (and the official response from Matrix.org).
