What Edu is reading this week (Feb 2 - 8, 2026)

Posted on Feb 8, 2026

This week the AI agent ecosystem gets a reality check with the Moltbook database exposure, while new tools like Fluid.sh and Sandbox Agent aim to make agentic infrastructure safer and more standardized.

AI, Agents & Security

  • Moltbook Database Exposure - Wiz reveals a security breach in “Moltbook” (a social network for agents) where an exposed database revealed millions of API keys.
  • Code on Incus - Run coding agents in isolated Incus containers (sandboxes) with session persistence, workspace isolation, and multi-slot support.
  • Nanobot - A lightweight (4,000 LOC) alternative to OpenClaw that delivers core AI assistant capabilities without the bloat.
  • Fluid.sh - A tool to create ephemeral KVM sandboxes where AI agents can execute infrastructure tasks safely before applying them to production.
  • Sandbox Agent - A universal API to control coding agents (Claude Code, OpenCode, etc.) inside sandboxes over HTTP.
  • Claudernetes - An ArgoCD plugin that uses Claude Code to dynamically generate Kubernetes manifests, reducing the need to write raw YAML.
  • AI Generated Code Quality - A discussion on the potential long-term quality problems introduced by AI-generated code.
  • Automation to Infection Part II - VirusTotal analyzes how attackers are leveraging automation and AI in modern infection chains.
  • My AI Adoption Journey - Mitchell Hashimoto reflects on his personal journey adopting AI tools.
  • The Adolescence of Technology - An essay by Dario Amodei on the current developmental stage of AI technology.

Cloud, Network & Tools

  • Fresh - A terminal text editor you can just use.
  • Whosthere - A TUI-based LAN discovery tool that scans for devices using mDNS, SSDP, and ARP.
  • WebZFS - A modern, web-based management interface for ZFS pools, datasets, and snapshots.
  • Nextcloud Ada Engine - Nextcloud introduces the Ada Engine, a new high-performance data access architecture.
  • Git Based Packaging - A workflow for managing software packaging using Git.

Privacy & Tunneling

  • Outline - Outline makes it easy to create a VPN server, giving anyone access to the free and open internet.
  • ByeDPI - A local SOCKS/HTTP proxy designed to bypass Deep Packet Inspection (DPI).
  • Chisel - A fast TCP/UDP tunnel over HTTP, useful for passing through restrictive firewalls.
  • WStunnel - A tool to tunnel traffic over WebSocket, allowing you to bypass firewalls that block standard VPN protocols.
  • Xray-core - A platform for building proxies to bypass network restrictions (Project X).
  • Shadowsocks - A secure socks5 proxy, designed to protect your internet traffic.
  • SoftEther VPN - One of the world’s most powerful and easy-to-use multi-protocol VPN software.

Gaming & General

  • Playdate Games - A repository or collection of games for the Playdate handheld console.
  • R36S Multiboot / Armbian: Resources for running multiple OSes and Armbian on the R36S retro handheld.
  • Mr. Doob - The personal site of the creator of Three.js, featuring various WebGL experiments.
  • Base64 Padding - A blog post explaining the purpose of the equals signs (=) at the end of Base64 strings.
